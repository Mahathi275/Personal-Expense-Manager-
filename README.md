# Personal Expense Manager Ecosystem

A high-performance, component-driven single-page React framework application designed to track transaction records, compute dynamic expenditure aggregates, and filter line items via custom category dropdowns.

This application fulfills the technical implementation criteria for **Project 3** under the Glow Logics evaluation track.

## 🚀 Repository & Live Parameters

- **Live Application URL:** [https://personal-expense-manager-2.netlify.app/]

## 🛠️ Technology Stack Built

- **Core Engine Framework:** React.js & Vite Build System
- **Reactive Data Pipelines:** Controlled hooks (`useState`)
- **Visual Skin Customization:** Modern dark CSS variable tokens & Bootstrap 5 structural utilities
- **Iconographic Interfaces:** Font Awesome Branding Kit

## 📂 Structural Workspace Tree

- `src/App.jsx` - Main mathematical calculations, filtering arrays, and parent shell layout
- `src/App.css` - Custom glassmorphic styles, dark theme variables, and row hover animations
- `src/components/ExpenseForm.jsx` - Input fields with submission validation parameters
- `src/components/ExpenseList.jsx` - Real-time active data tracking matrix lists
- `src/components/SummaryCard.jsx` - Analytical aggregation cards dashboard view
- `/screenshots` - Verification images showcasing system output records
